# Lumi English 固化课程题目表

这是题库固化前的总表。每一行对应一个旧版关卡 ID，旧 ID 会继续保留用于进度迁移。题目数据写入 `course-data/blocks/<lesson-id>.json` 后，必须通过 `tools/validate-authored-blocks.js` 才能进入课程加载器。

每个板块固定 10 题：

| 顺序 | 题型 | 目的 |
|---|---|---|
| 1 | word | 目标词直译与识别 |
| 2 | choice | 日常场景理解 |
| 3 | listen | 听力理解 |
| 4 | order | 语序与句型输出 |
| 5 | fill | 语法结构填空 |
| 6 | match | 6 组以上词义配对 |
| 7 | word | 第二目标词复习 |
| 8 | choice | 同一语法点的第二场景 |
| 9 | listen | 同一场景的第二听力 |
| 10 | fill | 语法点迁移到新句子 |

每个板块还必须填写：CEFR、主题、场景、目标词、语法重点、难度、对话场景和中文翻译策略。题目禁止引用“本课”“这个单词是什么意思”等元话语，禁止使用运行时模板生成句子。

## 分类规则

- A1：家庭、学校、餐厅、购物、交通、健康等可观察的日常场景；句子通常 5–10 词。
- A2：过去经历、计划、建议、比较、数量、服务沟通；句子通常 8–14 词。
- B1：工作、学习、旅行协作、观点表达；句子通常 10–18 词。
- B2：谈判、政策、研究、伦理、合同、复杂因果；句子通常 12–22 词。
- 每个板块只设置一个主语法点，10 题至少 8 题实际体现该语法点。
- 对话题必须有两个角色、至少三轮、完整翻译、自然回应和可播放句子。
