# Lumi English UI 重设计实施方案

> 版本：v1.0｜日期：2026-10-08｜状态：待确认

## 目标

将路线页和答题页改成明亮、清晰、有游戏感的商业化移动学习界面。采用“卡片章节 + 横向关卡带”作为路线骨架，吸收参考图中的白色留白、顶部状态条、章节横幅、圆形节点、厚底按钮、固定底部行动区和对话气泡，同时保留 Lumi 自己的色彩、角色、积分和无限学习规则。

本方案只改 UI、交互表现和展示层。题目 ID、本地进度、积分规则、系统 TTS、Android WebView 容器和课程数据接口保持兼容。

## 视觉规范

主色：蓝色 `#27AEE8`，深蓝底边 `#168DCA`，完成绿 `#58CC02`，深绿 `#46A900`，奖励黄 `#FFC800`，对话粉 `#F486C7`，主紫 `#6B62DF`，锁定灰 `#E8E8E8`。页面使用白底，分区使用 `#F7F8FA`，主文字 `#27313A`，辅助文字 `#7B8791`。

卡片圆角 16～20px，答案按钮圆角 16px，节点直径 60～72px。主要按钮保留 4～6px 深色底边制造触感。阴影统一使用低透明度浅阴影，避免大面积深色渐变。颜色不能作为唯一状态标识，必须同时显示图标、文字或形状差异。

## 路线页

页面顺序为：顶部状态条、今日学习摘要、Section 卡片、Unit 横向关卡带、语法指南、底部导航。

顶部状态条展示连胜、Lumi 积分、XP 和当前 CEFR，白底、轻分割线、小图标，减少垂直占用。

Section 卡片包含等级徽标、场景插画、章节名、短描述、完成数量和进度条。点击卡片展开或收起该等级；当前等级默认展开，其他等级默认收起。

Unit 以横向关卡带呈现，每个 Unit 显示主题、场景短句和 4～8 个节点。节点左右交错排列，使用短连接线，取消贯穿全屏的中央强竖线。节点类型如下：

- 普通 Lesson：蓝色星星
- 已完成 Lesson：绿色勾选星星
- Dialogue：粉色对话气泡
- Review：橙色耳机或闪电
- Checkpoint：黄色宝箱或奖杯
- Locked：灰色圆点或锁

当前节点增加“开始学习”小气泡、低频呼吸光和至少 48px 点击区域。每个 Section 或每 12 个 Unit 插入 Checkpoint 节点，显示解锁条件、通过状态和奖励状态。

## 答题页

顶部固定显示关闭按钮、绿色进度条、积分或复习标识。题型标签使用小号灰字，题目标题使用 26～30px 深色文字，指令使用 13～14px 辅助文字。题目区保持白底，听力题显示大号蓝色播放圆钮，题目插画或角色位于标题下方。

选择题统一为“选择 → 检查 → 底部反馈 → 继续”四步：答案按钮全宽、最小高度 56px、2px 边框、底部厚边；选中为浅蓝，正确为绿色，错误为红色。点击选项只选中，不立即结算。

听力题进入后自动播放一次，保留重播和慢速播放。播放中显示波纹状态。音频不可用时使用系统 TTS 回退。

拼句题顶部显示已选词块，可撤回；底部词块使用圆角按钮。填空题使用浅灰空缺胶囊，答对后反馈必须显示完整中文句意。配对题最少 6 对，点错只闪红，不扣整题分；全部配完后才结束。

对话题使用左右交错气泡、角色名和头像，目标句作答前隐藏，整段对话自动播放并支持重播、慢速和逐句播放。英文单词仍可点击查看直译，完整句子中文只在提交反馈后显示。

## 底部导航

学习舱、复习舱、个人舱三个入口保留。高度 72px 加安全区，图标 20px，文字 10～11px，当前项使用浅蓝背景。答题页隐藏底部导航，退出后恢复。所有按钮添加 `type`、`aria-current` 和可见焦点样式。

## 动效与音效

节点出现使用淡入上移，当前节点使用 2.4 秒呼吸光，答案选择使用 120ms 缩放，反馈区从底部 180ms 上滑，错误卡片轻微摇动，Checkpoint 完成播放宝箱和粒子效果。尊重 `prefers-reduced-motion`。

本地音效映射：选择 click，答对 correct，答错 wrong，五连击 combo，完成 complete，奖励 reward。系统 TTS 继续负责题目和对话语音。

## 代码改造范围

- `app.js`：Section 卡片、Unit 路线、节点类型、首页摘要和导航状态。
- `interaction.js`：统一答题页、选择/检查/反馈/继续流程、对话展示。
- `daylight.css`：基础明亮主题。
- 新增 `duo-reference.css`：路线节点、按钮、进度、对话气泡和参考风格覆盖层。
- `model.js`：继续使用现有积分、SRS、Checkpoint 和进度迁移接口。
- `audio.js`：继续使用本地音效和系统 TTS，不改变音频数据接口。

路线渲染只读取 `sectionId`、`unitId`、`lessonType`、`dialogue`、`checkpoint` 等元数据，不通过题目文本猜测节点类型。旧 lesson ID 和 `state.completed`、`state.mistakes`、`state.srs`、`checkpointResults` 全部保留。

## 响应式与无障碍

必须验证 320×640、360×800、390×844、412×915 和 768×1024。页面不能横向溢出，标题不能截断，底部按钮不能被系统手势区遮挡，节点和答案按钮点击区域至少 48px。

节点、播放按钮、反馈区、当前状态都提供 aria 标签。正确和错误状态同时使用颜色、文字和图标。键盘可以完成选择和检查。

## 实施顺序

1. 新增并加载 `duo-reference.css`。
2. 重做 Section 卡片和路线节点带。
3. 加入 Dialogue、Review、Checkpoint 节点样式。
4. 重做答题标题、答案按钮、检查按钮和固定反馈区。
5. 重做听力、填空、拼句、配对和对话布局。
6. 加入节点、反馈、奖励和吉祥物动效。
7. 在 320px、390px 和 768px 宽度下做浏览器检查。
8. 运行全量 Node 测试、内容审计、语法审计和题块审计。
9. 使用当前源码重建 APK，执行 `apksigner verify`。

## 验收标准

- Section 卡片信息层级清楚。
- 路线使用左右交错节点，不再出现抢眼的中央贯穿线。
- 当前节点有明确“开始学习”提示。
- 普通、完成、锁定、对话、复习、Checkpoint 状态易于区分。
- 底部导航图标保持小尺寸，文字不被放大。
- 选择题必须先选择再检查。
- 正确和错误反馈固定在底部，继续按钮稳定可见。
- 听力进入自动播放一次，慢速播放有效。
- 填空答对显示完整中文释义。
- 对话目标句不提前泄露，单词可点击查看直译。
- 全量测试通过、审计无错误、APK 重新构建并签名验证通过。
