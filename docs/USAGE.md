# Lumi English 使用说明

这份文档按 App 里实际的界面顺序写，所有名称都和手机上显示的一致。

---

## 界面总览

底部三个标签，任何时候都能切换：

| 标签 | 作用 |
|---|---|
| **学习舱** | 主界面。今日任务、每日目标、学习路线、语法指南 |
| **复习舱** | 复习小屋。错题回顾、快速练习、主动输出训练 |
| **个人舱** | 我的小岛。积分商店、成就徽章、冒险进度、设置 |

顶栏右侧三个数字，从左到右是：

- 🔥 **连续天数** —— 连续学习的天数
- ⚡ **连击** —— 连续答对的题数
- ⭐ **积分** —— 全局通用货币

---

## 首次启动

第一次打开是六步引导：

1. **你的目的地** —— 日常沟通 / 出国旅行 / 工作交流 / 综合提升
2. **你的英语背景** —— 零基础到六级，或「不确定」
3. **你的目标等级** —— A1 / A2 / B1 / B2
4. **每日节奏** —— 5 到 30 分钟，对应每天大约几关
5. **每日提醒时间** —— 本地通知，不联网
6. **等级测试** —— 几道题帮你定位起点

第 6 步可以点「**稍后再测，直接开始**」跳过，这时会按第 2 步选的英语背景推荐起始等级，并自动把低于该等级的课程标记为已完成。

想重走引导：个人舱 → 设置 → 重新开始。

## 学习舱

### 今日三项挑战

每天刷新的三个小目标，完成后给积分，比如「完成 2 个新关卡 +20」「答对 20 道不同题 +15」「正确复习 10 道不同题 +20」。

### 今日目标

当天的 XP 进度条。攒满后右下角出现 **+30** 按钮，点它领取当天奖励——**不点就领不到**。旁边的「调整」可以改每日目标。

### 学习路线

整条路线按 CEFR 分成 A1 → A2 → B1 → B2 四段，每段 72 关。完成一关才能解锁下一关。每个区段（Checkpoint）全部通关后会触发区段结算。

### 语法指南

路线图下方是按等级整理的语法卡片，讲这个阶段会碰到的语法点，随课程进度逐步解锁。

## 答题

一关 12 道题，题型每次开课会随机打乱顺序。

### 七种题型

| 题型 | 说明 |
|---|---|
| **单词** | 给一个英文单词，选中文释义。单词本身可以点，会朗读 |
| **句子·认识句子** | 给英文句子，选中文意思 |
| **听一听** | 自动播放一次英语，选听到的意思。可重播、可切慢速 |
| **拼一拼** | 给中文，把打乱的英文单词块拼成句子 |
| **填一填** | 句子留一个空，从选项里选正确的词 |
| **配一配** | 英文和中文配对，至少 6 对 |
| **情景对白** | 一段对话，选择合适的回应 |

### 作答规则

- **题目一开始不给完整翻译**。句子里的英文单词可以单独点开看释义（虚线下划线的词），但完整翻译要提交答案之后才显示。
- 选完答案点「**检查答案**」，底部会展开反馈：答对了给确认，答错了会显示正确答案。
- **答错的题会回到本关队列末尾**，必须把错题也做对才能通关。同一关重复练习不会重复发题目 XP。
- 听力题进入后会**自动播放一次**，之后可以随时重播。
- 题目卡上的「**提示 · 3 积分**」可以花 3 积分隐藏一个错误选项。

### 题目卡右上角的猫

是 Lumi，会跟着你的答题换表情：答对了高兴、答错了难过、连击高了会欢呼。

## 积分与激励

积分只用来换便利和外观，**不会限制你能学多少**。

- **每日 XP 目标** —— 每天清零，攒满领取
- **连续天数** —— 每天学一次就续上。中断可以靠「连胜保护」抵消一次
- **连击** —— 连续答对会累积
- **成就徽章** —— 个人舱里查看
- **积分商店** —— 见下

### 积分商店（个人舱）

| 商品 | 价格 | 作用 |
|---|---|---|
| Lumi 星光表情 | 80 | 外观 |
| 夜空路线主题 | 160 | 外观 |
| 复习加成卡 | 120 | 复习时收益加成 |
| 连胜保护 | 240 | 断签时自动保住连胜一次 |

## 复习舱

### 错题回顾

做错过的题会进这里，按到期时间优先推送。刚开始用还没有内容，完成几节课后会出现。

### 快速练习

- **听力热身** —— 回到第一站，重新听一遍
- **句子练习** —— 复习翻译和语序

### 主动输出

- **看中文打英文** —— 真正的输出训练，需要你把句子打出来而不是选
- **听写挑战** —— 听懂后准确写出来，进入后自动播放一次

## 个人舱

### 我的小岛

显示当前等级称号（如「Lv. 1 英语探险家」）、积分商店、成就徽章和冒险进度。

### 设置

| 选项 | 说明 |
|---|---|
| **英语发音** | 使用手机系统 TTS 播放 |
| **系统语音设置** | 检查英语语音包和默认 TTS 引擎，点进去会跳系统设置 |
| **奖励动效** | 开关答题动效，默认开启 |
| **背景音乐** | 开关，默认关闭 |
| **重新开始** | **清除本机全部学习进度**，会二次确认 |

## 朗读没有声音怎么办

本应用**不内置语音包**，朗读全部由 Android 系统的 TextToSpeech 引擎实时生成。没声音通常是系统侧的问题：

1. 个人舱 → 设置 → **系统语音设置**，看默认 TTS 引擎是哪个
2. 进入该引擎的设置，确认**英语（en-US / en-GB）语音数据已下载**
3. 部分手机的英语语音包需要联网下载，且体积不小
4. 换一个 TTS 引擎（系统自带 / Google / 讯飞等）通常能解决音色奇怪或语速不对的问题

慢速播放走的是同一个引擎的 `setSpeechRate`，所以慢速效果也取决于引擎实现。

## 桌面小组件

长按手机桌面 → **小组件** → **Lumi English** → 拖到桌面。

显示今日 XP、目标进度和连续学习天数。完成一关后会自动同步，不需要手动刷新。

> 小组件和每日提醒都是本机实现，受手机的后台限制影响。如果看不到更新，检查系统是否限制了本应用的后台活动。

## 常见问题

**进度会丢吗？**

进度只存在手机本地，没有账号也没有云同步。清除应用数据、卸载重装或换手机都会丢失。换手机前可以用「个人舱 → 设置」里的信息确认当前状态，但目前没有导出功能。

**可以覆盖安装升级吗？**

同一作者签名的 APK 可以覆盖安装。从别处下载的同名应用签名不同，无法直接覆盖，需要先卸载。

**为什么答错了还要重做？**

这是刻意设计：答错的题会回到本关队列，确保你真正掌握才放行。但也因此不会重复发题目 XP，不会靠刷同一关刷分。

**每天大概学多久？**

引导里选的每日节奏会决定每日 XP 目标。5 分钟大约 1 关，30 分钟大约 6 关。目标可以在「今日目标 → 调整」里改。
